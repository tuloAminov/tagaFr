# Персональный сайт-портфолио Fullstack-разработчика

Минималистичный, адаптивный сайт-портфолио в темной теме с 3D-градиентными размытыми пятнами, анимациями Framer Motion и изолированным хранилищем контента в `data.js`.

---

## 🛠 Стек технологий
- **Фреймворк:** React 19 + Vite
- **Стилизация:** Tailwind CSS
- **Анимации:** Framer Motion
- **Иконки:** Lucide React + Pixel-perfect SVG (GitHub, Telegram)
- **Шрифты:** Inter & JetBrains Mono (Google Fonts)

---

## 🚀 Запуск и сборка

1. **Запуск в режиме разработки:**
   ```bash
   npm run dev
   ```
   Открой адрес [http://localhost:5173](http://localhost:5173) в браузере.

2. **Сборка для продакшена:**
   ```bash
   npm run build
   ```
   Готовые оптимизированные статические файлы будут в директории `dist/`.

3. **Локальный предпросмотр сборки:**
   ```bash
   npm run preview
   ```

## ✏️ Как редактировать контент

Весь контент вынесен в файл **`src/data.js`**. Для кастомизации под себя достаточно отредактировать:

- `personalData.brand` — твой никнейм/домен.
- `personalData.name` — имя заглавными буквами.
- `personalData.specialization` — специализация через буллиты `•`.
- `personalData.bio` — краткое резюме на 2-3 предложения.
- `personalData.contacts` — email, ссылки на Telegram, GitHub, город и готовность к переезду.
- `experiences` — список мест работы (должность, компания, даты, буллиты обязанностей).
- `projects` — проекты (название, описание, массив технологий, ссылки).
- `educations` — образование (степень, ВУЗ, года, направление).
- `techStack` — используемые технологии.
- `beyondCode` — достижения, хобби и интересы.
- `personalData.footer` — подписи в футере.

## 📄 Экспорт в PDF

На странице "Резюме" справа внизу расположена кнопка **"↓ PDF"**. При нажатии открывается системный диалог печати браузера `window.print()`, для которого настроен специальный медиа-запрос `@media print` в `src/index.css`:
- Скрывается навигация, фоновые светящиеся пятна и интерактивные кнопки.
- Оптимизируется верстка карточек и переносов страниц (`break-inside: avoid`).
- Резюме сохраняется в аккуратном белом печатном виде при выборе "Сохранить как PDF".
